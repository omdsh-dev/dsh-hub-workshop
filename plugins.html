最新探测如何工作

Hub 每 6 小时刷新公开发现数据，重新读取变更的项目，并让未变更项目的探测缓存最多保留 24 小时。依赖范围会与 npm 当前发布的 DSH 版本对照。网络失败会明确显示，历史成功结果不会被改写为新结果。

文件探测不是运行测试。项目详情会分别显示源码更新时间、最近尝试时间与成功读取时间。

数据边界

Marketplace JSON 提供最新市场目录与探测记录；Catalog JSON 提供有文件级证据的插件；Topic Snapshot JSON 保留完整公开候选来源快照；Plugin Audit JSON 公开每个仓库的插件、生态层或排除结论；Registry JSON 只发布经过固定版本、供应链、真实运行和恢复门禁的安装条目。
